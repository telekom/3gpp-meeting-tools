# Pill & Tag UI Package (`modules.meetings.ui.pills`)

Acyclic modular package extracted from `ui/topic_pills.py` (thin backward-compatible re-export shim):

- `wg_and_filter_pills.py`: `get_wg_colors()`, `WgTogglePill`, and `FilterPillButton`.
- `tag_cloud.py`: `TagPillItem`, `_TagLineEdit`, and `TagCloudWidget` (with autocomplete and strict searchable dropdown).
- `agenda_item_pills.py`: `AgendaItemPill` and `AgendaItemPillsWidget`.
