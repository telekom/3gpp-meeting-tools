# UI Shell, Typography Scaling & Styling Reference

Detailed architecture reference for the responsive desktop shell (`src/main_window.py`, `src/core/ui/`). For concise mandatory rules, see root [`AGENTS.md`](../AGENTS.md).

---

## 1. Responsive App Shell (`src/main_window.py`, `src/core/ui/`)

- **`NavRail` (`nav_rail.py`) & `icons.py`:** Lucide SVG icons drive the hidden `QTabWidget` (`self.tabs`, `QSizePolicy.Ignored` with `DragDropUI.setMinimumSize(780, 560)` so large child tabs never lock laptop window widths above `1040 px`, preserving all `.tabs.` API callers).
  - Responsive breakpoint hysteresis: `<1040 px` collapse / `>=1070 px` expand, tightening to `<1280 px` / `>=1310 px` when `RightSidePanel` is open.
  - Top `Search…  Ctrl+K` trigger button (`cmdk_btn`, intentionally excluded from `ordered_focus_widgets()`).
  - Rail footer `Help & Docs` + `Settings` menus (including `🔁 Restart Application` wired to `DragDropUI.restart_application()` and `core.updater.app_updater.spawn_detached_relaunch()`).
  - Global shortcuts: `Ctrl+1..9` tabs, `Ctrl+K` Command Palette, `Ctrl+Shift+R` Restart Application, `Ctrl+Shift+A` Assistant dock, `Ctrl+Shift+F` Quick Spec Search dock, `Ctrl+\` rail toggle, `Ctrl+J` drawer toggle, `F1` docs.
- **`SystemStatusBar` ([`status_bar/`](../src/core/ui/status_bar/README.md), `system_status_bar.py` shim):** Implements dynamic content-driven **Minimalist Mode** (`compute_full_required_width()` + `apply_responsive_width()` with `24 px` hysteresis, wired in `DragDropUI._setup_ui`, `DragDropUI.resizeEvent`, `restore_shell_state`, `SystemStatusBar.resizeEvent`, `messageChanged`, `font_scale` changes, and live pill updates).
  - Whenever available width is narrower than measured full-mode width of the left status message plus all active pills, collapses action & status pills (`Ollama`, `MCP`, `Proxy`, `System`, `Assistant`, `Quick Search`, and idle `Console & Queue`) to compact icon-only badges with full tooltips.
  - Hides non-3GPP Wi-Fi labels while surfacing `🟢 3GPP` / `🟡 3GPP` on a 3GPP meeting network; surfaces compact queue/error counts (`N` / `M!`); preserves full local/UTC/venue time readability in `clock_indicator` (`format_status_bar_text(..., compact=True)` omits only the trailing `(WG)` tag and caps >2 split venues).
- **`RightSidePanel` (`right_side_panel.py`):** Hosts `MODE_ASSISTANT` and `MODE_SPEC_SEARCH` inside a horizontal `QSplitter` alongside `self.tabs` (`320..560 px` clamped width, default `390 px`), toggled from `SystemStatusBar` checkable dock pills (`assistant_dock_btn`, `search_dock_btn`) or `Ctrl+Shift+A` / `Ctrl+Shift+F`, with 1-click promotion (`⤢ Full View`) and cooperative worker shutdown in `DragDropUI.closeEvent`.
- **`CommandPaletteDialog` (`command_palette.py`):** `<kbd>Ctrl+K</kbd>` keyboard-first navigation across all 9 pages, Word Studio sub-workbenches (`WordExtractorTab.open_workbench`), right-dock actions, and live SQLite lookup for Specifications, Meetings & TDocs (`find_meeting_by_tdoc`), Work Items (`search_work_item_suggestions`), and Protocol messages (`nas_messages`), routed through filter-clearing deep-link helpers (`SpecificationsTab.select_and_show_spec`, `MeetingsTab.focus_meeting`, `WorkItemsTab.focus_work_item`).
- **`BottomDrawer` (`bottom_drawer.py`):** Wraps `ConsolePanel` and `QueuePanel`, toggled from `SystemStatusBar` with live queue/unread-error badges; system tool shortcuts live in `SystemStatusBar.system_menu` and `Settings` (including [`DatabaseMaintenanceDialog`](../src/core/ui/database_maintenance/README.md) via its `database_maintenance_dialog.py` shim).
- **World Clock & Active 3GPP Venue Clocks (`world_clock_service.py`, `world_clock_dialog.py`, `SystemStatusBar`, `TDocsWindow`):** Live `clock_indicator` pill in `SystemStatusBar` displaying Laptop Local Time (IT-locked OS clock), Official 3GPP UTC, and active in-person 3GPP venue times (grouping co-located WGs by city, displaying all active cities during split weeks, appending `(-1d)`/`(+1d)` day-rollover badges, and falling back to next upcoming venues during off-weeks). Supports Working Group filtering (`wg_filter` in `meetings_config.json`), 3-tier timezone resolution (`manual_override` in `<meeting_dir>/meeting_timezone.json` & `meetings_config.json` > public Web Geocoding/Timezone sync via Open-Meteo + TimeAPI.io / physical Geo-IP via `ipwho.is` > expanded offline `zoneinfo`/city fallback), `-1h`/`+1h` DST nudges, and contextual per-meeting header pills inside `TDocsWindow`.
- **`ToastManager` (`toast.py`):** Renders non-blocking completion notifications (`[Open]`, `[Show in Folder]`) on `QueueManager` successes, shifting horizontally left of `RightSidePanel` whenever the dock is open, with `notify_success()` / `notify_info()` helpers for tabs to replace modal `QMessageBox.information` success popups.
- **`PageRibbonCard` (`page_ribbon.py`):** Shared 2-tier carded header, contextual full-width `add_banner_widget()` slot, and responsive `FlowLayout` filter bar (`apply_lucide_icon`, `make_filter_label`) adopted across tabs (`MeetingsTab` with independently wrapping Quick TDoc action buttons + collapsible `#tdocMetadataBanner` holding `tdoc_metadata_warning` (`wordWrap=True`) and `btn_update_tdoc_metadata` + `table_card` footer; `SpecSearchTab.search_ribbon`; `SpecificationsTab.ribbon_card` + `table_card`; `WorkItemsTab.ribbon_card` + `table_card`; `NASTab.ribbon_card`; `AssistantTab.ribbon_card`; `CodeEditorTab.ribbon_card` & `BatchConvertTab` studio).
- **`shell_state.py`:** Persists window geometry (screen-clamped), rail/drawer/splitter states, `right_panel/*` dock state (`open`, `mode`, `preferred_width`), and last active tab via `QSettings`.
- **`window_session.py`:** Captures open primary workspace windows (`TDocsWindow`, `SessionPlanWindow`, `EmailManagerWindow`, `MeetingEmailInboxDialog`, `TopicDossierDialog`, `AgreementTrackerDialog`, `ContributionReportDialog`, `SpecVersionHistoryDialog`, `SpecClauseExcerptDialog`, `SpecClauseDiffDialog`, `CrPcrDialog`) at the start of `DragDropUI.closeEvent()` (preserving screen-clamped geometry and key in-window state via `get_session_state()`/`restore_session_state()`) and reopens them asynchronously after `window.show()` (`QTimer.singleShot(0, ...)`). Controlled via the Settings `🪟 Restore Open Windows` submenu (`always` [default], `restart_only` triggered by `DragDropUI.restart_application()` / `AppUpdateDialog` restarts via a one-shot `pending_restart_restore` flag, or `off`), with `--no-restore` and `Shift`-held startup escape hatches.

## 2. Typography Scaling & Accessibility (`src/core/ui/font_scale.py`, `display_settings_dialog.py`)

Per-machine typography scaling (`0.85`–`1.60`) is persisted in `QSettings` and applied globally across the QSS theme, inline rich-text HTML (`QLabel`, `QTextEdit`, `QTextBrowser`, `QTextDocument` via `scale_html_fonts()`), and registered widgets:

- **Scale strictly in logical pixels:** Use `scale_px()`, `scaled_font()`, and `register_scaled_row_height()` rather than `setPointSize()` / `scale_pt()` / `QFont(..., pt)`. Because `load_app_fonts()` and `GLOBAL_STYLE` size controls in `px` (`T.SIZE_BODY` = 13 px, `T.SIZE_TABLE` = 12 px, `T.SIZE_CAPTION` = 11 px), point-sized fonts are multiplied by Windows DPI scaling (`125%`/`150%+`) while pixel-sized table cells/headers are not, causing pill badges and custom delegates (`meetings_delegates.py`, `tdoc_delegates.py`, `work_items_delegates.py`, `nas_components.py`, `spec_search_components.py`) to render disproportionately larger than surrounding text.
- **Static bold/family items:** For static `QTableWidgetItem`s or `QTreeWidgetItem`s that only need bold/family styling, set `f.setBold(True)` / `f.setFamily(...)` without setting `pixelSize` so Qt leaves `SizeResolved` unset and inherits the table's live-scaled QSS `font-size`.
- **Flexible heights/widths:** Prefer `setMinimumHeight(scale_px(...))` over rigid `setFixedHeight(...)` or unscaled `setMaximumWidth(...)` so filter bars, buttons, and table cells never clip at `125%`–`160%`.
- **ComboBoxes & scoped selectors:** Use `QComboBox.AdjustToContents` (and `CheckableComboBox` summary-label `sizeHint()`/`minimumSizeHint()`, `#checkableComboPopupView` + `CheckableComboItemDelegate` theme-aware checkbox rendering, and `.QWidget { background: transparent; border: none; }` scoped container selectors so transparent wrapper styles never turn `Fusion` popup checkboxes black) and subscribe dynamic widgets to `get_font_scale_notifier().scale_changed` so dropdown widths reflow cleanly without inflating `TDocsWindow` or tab minimum widths.
- **Live target-scale previews:** Inside dialogs, use `set_unscaled_stylesheet()` (sets `_font_scale_ignore`) so preview widgets render exact target `Body / Table / Caption` pixel sizes without double-scaling when `apply_font_scale()` rescales global stylesheets.

## 3. Design Tokens, Raw-Hex Governance & Component Reuse

- **Tokens (`src/core/ui/theme.py`):** All new UI code and migrated modules must reference tokens from `core.ui.theme` (`C`, `T`, `R`, `S`, `B`) rather than hardcoded `#RRGGBB` literals. Enforced by `tests/test_ui_hex_lint.py` (zero tolerance in new/migrated files; no-growth ratchet on legacy allowlisted files). Preview automated substitutions with `py -3.14 -m core.ui.hex_migrator <path> --dry-run --diff`.
- **Shared styles (`src/core/ui/ui_components.py` shim $\to$ `src/core/ui/components/`, `src/core/ui/drop_zone.py` shim $\to$ `src/core/ui/components/drop_zone/`):** Prefer `BUTTON_STYLE_TOOLBAR_SECONDARY`, `CARD_FRAME_STYLE`, `BADGE_STYLE_*`, `TABLE_STYLE_CLEAN`, and `ModernDropZone` over ad-hoc inline stylesheets (see [`src/core/ui/components/README.md`](../src/core/ui/components/README.md) and [`src/core/ui/components/drop_zone/README.md`](../src/core/ui/components/drop_zone/README.md)).
- **Interactive states:** Checkable buttons / toggleable controls must define `QPushButton:checked` and `QPushButton:checked:hover` using `C.ACCENT_SOFT` / `C.ACCENT_PRIMARY`.
- **Windows Taskbar Icon & Native Shell Identity (`core.ui.ui_components`):**
  - `src/assets/3gpp_tools.ico` must remain a multi-resolution `.ico` container (`16`, `24`, `32`, `48`, `64`, `128`, `256` px).
  - `create_app_icon()` pre-hydrates OneDrive Files On-Demand placeholders (`_hydrate_file_if_needed()`), loads `3gpp_tools.ico` and `3gpp_tools.png` across all standard DPI sizes (`16..256` px) with an in-memory vector fallback (`_render_fallback_pixmap()`), and caches the resulting `QIcon`.
  - `apply_native_window_icon()` + `install_window_icon_manager(app)` (`main_tools.py`, `main_window.py`) install a global `QEvent.Show` / `QEvent.WinIdChange` filter that stamps every top-level `Qt.Window` and `Qt.Dialog` (including standalone `super().__init__(None)` windows whose `HWND` is recreated by `setWindowFlags(Qt.Window)`) with native Win32 `WM_SETICON` (`ICON_BIG`/`ICON_SMALL`), `SetClassLongPtrW` class icons, and `SHGetPropertyStoreForWindow` `IPropertyStore` shell properties (`PKEY_AppUserModel_ID`, `PKEY_AppUserModel_RelaunchIconResource`, `PKEY_AppUserModel_RelaunchDisplayNameResource`), as well as setting the attached launcher console icon (`GetConsoleWindow()`). Covered by `tests/test_taskbar_icon.py`.
